# Repository audit and repairs

**What this repo does:** Court Vision imports NBA statistics and Yahoo fantasy leagues, then serves player rankings, rosters, watchlists and weekly matchups. Shared libraries supply the valuation engine and design system to three other sport shells and a Chrome extension.

**Baseline:** `5b46335c9bee5742ea29fbdbc28b32cc4c3a7080`. The initial review assumed a public, multi-user Netlify deployment, a shared Supabase database, concurrent browser tabs/server actions, and scheduled imports. The original audit-only delivery was incomplete; this PR now contains the repairs, regression tests and enforcement below.

## Additional compliance repairs

- Replaced the reported hardcoded spacing with a shared token and classified the three bare test-fixture `div` elements.
- Kept Bun's required matcher interface augmentation, documenting its narrow exception in `CLAUDE.md` rather than breaking declaration merging.
- Tightened import rules to reject sibling-relative imports outside source overrides and prevent sport libraries from importing arbitrary workspace packages.
- Removed the relative package import from Next configuration. Its package metadata is read with the standard library and checked with an assertion; Next's config compiler was verified in type generation and production builds.
- Declared the already-installed Babel parser as an exact root development dependency because the new syntax-aware quality check imports it directly. No new runtime dependency was introduced.
- Updated the security scanner's public-signup exception to describe the implemented request budget instead of claiming the old rate-limit debt remains open. Intentional public authentication actions remain public.

## Deployment requirement

Apply `apps/court-vision/prisma/migrations/20261026000100_sync_leases_and_request_limits/migration.sql` **before deploying this application revision**:

```bash
bun run --cwd apps/court-vision db:deploy
```

Verify `DIRECT_URL`/`DATABASE_URL` before running it. The migration adds nullable `League.syncStartedAt` / `syncLeaseUntil` columns and the private `RequestRateLimit` table. It does not rewrite existing league data. Client generation was run locally; production migrations were deliberately not applied by this review.

CI now runs the database tests against a dedicated Postgres service. Local database tests reject non-loopback hosts and database names without the `_test` suffix. Never give those tests an application database.

## Remaining limits

**Verdict:** The nine reported findings have repairs and regression coverage. The broad type cleanup is mechanical; correctness/security changes are covered separately by unit, browser and actual database tests.

**Not checked:** Production Supabase grants/RLS or migration state; live provider responses; external dependency advisories; production load; authenticated production journeys; full manual screen-reader/contrast coverage across every theme. Netlify deployment behavior was not exercised against the live site. These checks are not replaced by a green scanner or unit suite.
